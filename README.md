# 🎰 송지섭 뽑기 대전

코인으로 랜덤 캐릭터를 뽑고 봇과 자동 전투를 하는 모바일 대응 밈 게임입니다.

## 플레이 방법
1. [게임 페이지](https://solidrocketbooster20110330-afk.github.io/Song-ji-sub/)를 열어요.
2. **50 코인으로 뽑기** 버튼으로 캐릭터를 획득해요.
3. 내 캐릭터 목록에서 출전할 캐릭터를 선택해요.
4. **봇과 자동 전투**로 승리하고 코인을 모아요.
5. 오늘의 무료 코인 보상도 잊지 마세요.

## 등급 및 확률
- 일반: 52%
- 레어: 28%
- 에픽: 14%
- 전설: 5%
- 초월: 1%

## 실행
정적 웹 게임이라 `index.html`을 브라우저에서 열면 됩니다. GitHub Pages를 켜면 위 주소로 공개할 수 있어요.

> 친구들끼리 즐기는 비공식 밈 게임입니다. 저장은 브라우저 세션 내에서만 유지되며, 서버 계정이나 온라인 멀티플레이는 포함되지 않습니다.
